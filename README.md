# BerukSakti

Halaman depan search engine pribadi bernama **BerukSakti**, dengan tampilan bergaya Google.

## Isi folder

| File | Keterangan |
|------|------------|
| `google-search.html` | Halaman search engine BerukSakti (HTML, CSS dan JavaScript dalam satu file) |
| `README.md` | File ini, penjelasan isi folder |

## Cara membuka

Klik dua kali `google-search.html`, atau seret file itu ke Chrome atau Edge. Tidak perlu server atau instalasi apa pun.

## Fitur

- Logo BerukSakti berwarna dan kotak pencarian bulat
- Pencarian dengan Enter atau tombol **Penelusuran BerukSakti**
- Tombol **Saya Lagi Beruntung** untuk langsung membuka hasil pertama
- Tombol **Chat with AI** untuk membuka Claude (claude.ai) dengan isi kotak pencarian sebagai pertanyaan
- Saran pencarian saat mengetik, dari riwayat pencarian (disimpan di browser) dan contoh kata kunci; bisa dipilih dengan panah atas/bawah
- Pencarian suara lewat tombol mikrofon (bahasa Indonesia, hanya di Chrome atau Edge)
- Tombol ✕ untuk menghapus teks
- Tekan `/` untuk langsung ke kotak pencarian
- Selalu tampil dalam mode gelap
- Tampilan menyesuaikan di layar HP

## Catatan

- Halaman ini hanya tampilan depan. Hasil pencarian tetap dibuka di Google, dan Chat with AI dibuka di claude.ai.
- Link di header dan footer (Gmail, Gambar, Login, Privasi, dan lainnya) mengarah ke situs Google.
